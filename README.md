# Портфолио — Екатерина Попова (AI Creator & Specialist)

Статический сайт-портфолио. Одностраничный `index.html` + медиа в папке `assets/`.

## Что изменилось (оптимизация)
- Раньше: один файл `portfolio.html` весом **35,6 МБ** — все фото и видео были вшиты в HTML как base64. Браузер скачивал все 35 МБ до первого показа.
- Сейчас: `index.html` весит **~100 КБ**, а 128 медиа (88 фото, 21 видео, 19 webp) вынесены в `assets/` и грузятся лениво (`loading="lazy"`, видео — `preload="none"` с постерами). Первый экран открывается практически мгновенно.

## Структура
```
index.html          — страница
assets/             — все фото и видео (имена = хэш содержимого)
assets/posters/     — обложки-кадры для видео
favicon.svg         — иконка
og-image.jpg        — превью для соцсетей и Telegram
vercel.json         — заголовки кэширования и безопасности
```

## Публикация
Любой статический хостинг: Vercel, GitHub Pages, Netlify, Cloudflare Pages.
Достаточно раздавать содержимое этой папки как есть.

Перед деплоем заменить в `index.html` плейсхолдер `__SITE_URL__` на реальный адрес сайта
(нужно для корректного превью в Telegram/соцсетях).
