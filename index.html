Реальные проекты

Кейсы из практики

01
Чат-бот в Bitrix24 на Perplexity API
Спроектировала логику и методику ответов. Реализовала чат-бот внутри Bitrix24 — бот по API обращается к Perplexity и возвращает структурированные ответы строго по методике компании.
Результат: рабочий инструмент внутри привычной среды — единообразные, предсказуемые ответы без ручного поиска.
02
Аналитика Wildberries + МойСклад — дашборд и автообновление
Система соединяет два источника: WB (продажи, заказы, возвраты, остатки) и МойСклад (карточки, приходы, склад). Автоматическое ночное обновление ~03:00 МСК, ручной маппинг товаров WB↔МС. Листы: Дашборд, Оборачиваемость (FIFO), Топ продаж, Дефицит, Возвраты, Партии.
Результат: единая аналитика без ручного копирования — данные по выручке, запасам и оборачиваемости всегда актуальны.
03
Логистический дашборд S&OP: out-of-stock / overstock
Проект дашборда для процесса S&OP с показателями дефицита и излишков. Система рассчитывает риски по каждой позиции и формирует управленческие рекомендации — когда скорректировать закупки, перераспределить запасы или пересмотреть план спроса. Цель: раннее выявление рисков до того, как они влияют на продажи.
Результат: повышение точности управления запасами, сокращение ситуаций дефицита и затоваривания.
04
ИИ-аватары и видео-персонажи для контента
Создала 6 разных ИИ-аватаров — реалистичных и мультяшных. Полный цикл: концепция → генерация → голос (ElevenLabs / HeyGen) → тест. Еженедельные ИИ-новости для TG-канала с аватаром-спикером, снятым один раз.
Результат: живой контент каждую неделю без съёмок и без найма актёра.
05
AI-персоны и ассистенты для разных ролей
Узкие ассистенты под конкретные задачи: юрист, JTBD-аналитик, тренажёр возражений для продавцов, помощник по техдокументам (Gemini + NotebookLM). Для каждого — системный промпт, структура диалога, сценарии и примеры.
Результат: сокращение рутины у юристов, маркетологов, продавцов и техписателей.
06
Внутренняя LMS с ИИ-ассистентом (Битрикс24)
С нуля спроектировала и реализовала обучающую платформу через вайбкодинг. Интегрирована локальным приложением в Битрикс24: курсы, тесты, роли — внутри корпоративного портала. ИИ-ассистент объясняет темы, задаёт вопросы, отрабатывает навыки в диалоге. Пилот с реальными пользователями.
Результат: LMS встроена в привычную среду — сотрудники обучаются без смены приложения.
07
Обучающие курсы с ИИ: PDF, презентации, видео, тесты
Разрабатываю обучающие материалы на разные темы с использованием ИИ-инструментов: структурированные PDF-гайды, презентации, объяснительные видео, тесты и практические задания. Часть курсов адаптирована под международную аудиторию — с локализацией на другие языки и рынки.
Результат: готовые к внедрению учебные продукты, которые можно масштабировать без привлечения методистов.
08
ИИ-агент для службы поддержки на базе знаний
Задача: создать и внедрить ИИ-агента, который сократит время поиска информации сотрудниками поддержки за счёт структурированной базы знаний. Агент обрабатывает обращения, находит релевантные ответы и формирует готовые реплики. Целевой показатель точности — не менее 90%.
Результат: сокращение времени обработки обращений, снижение нагрузки на опытных сотрудников.
09
Тренажёр продаж — ИИ-симулятор клиента (вайбкодинг)
Собрала на вайбкодинге веб-приложение для тренировки менеджеров: два режима на одном сайте — розница и интернет-магазин. Внутри база знаний, прописанные сценарии диалогов и рандомизация реплик и тем, чтобы каждая сессия была разной. ИИ-агент играет роль клиента: задаёт вопросы, отрабатывает возражения, ведёт диалог — а в конце выставляет менеджеру оценку по разговору.
Результат: розница + интернет-магазин на одном сайте, разные сценарии и автоматическая оценка диалога — тренировка без участия живого тренера.
10
Личный AI-агент для hh.ru + Telegram-бот
Сделала персонального агента под hh.ru: просматривает подходящие вакансии, откликается и отвечает на вопросы в анкетах работодателей. Управление и уведомления — через связку с Telegram-ботом, чтобы держать весь процесс под контролем прямо из мессенджера.
Результат: авто-отклики и заполнение анкет на hh.ru с управлением через Telegram-бота — экономия часов ручной рутины.
